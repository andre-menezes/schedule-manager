# Pendências — Agenda

Decisões que o levantamento **não** conseguiu fechar sozinho (política
anti-achismo, `agent/core/CONTRACT.md`). Cada uma tem uma recomendação; ao
decidir, registre a resposta aqui e, se for arquitetural, numa ADR (ou mude a
ADR de `Proposta` para `Aceita`).

Voltar para o índice: [README.md](README.md)

| ID   | Pergunta                                                                                                                                             | Impacto | Recomendação                                                                                                                                                | Bloqueia       | Status |
| ---- | ---------------------------------------------------------------------------------------------------------------------------------------------------- | ------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------- | ------ |
| Q-01 | Qual a stack e onde fica o backend (linguagem, banco, hospedagem)? Quem desenvolve?                                                                  | Alto    | API REST em repositório próprio, PostgreSQL, contrato OpenAPI primeiro (ADR-0049).                                                                          | R0             | Aberta |
| Q-02 | Modelo de negócio: gratuito, freemium ou assinatura? Quais limites por plano?                                                                        | Alto    | Freemium: pessoal grátis; profissional com período de teste. Define limites de clientes e de lembretes.                                                     | R1 (limites)   | Aberta |
| Q-03 | O agendamento online (link público) entra no MVP?                                                                                                    | Alto    | Não: R2. O MVP valida a agenda do profissional; o link depende de disponibilidade madura.                                                                   | Roadmap        | Aberta |
| Q-04 | Provedor e custo do WhatsApp (API oficial da Meta ou intermediário)? Quem paga a mensagem?                                                           | Alto    | API oficial via um BSP; custo embutido no plano pago (ADR-0053).                                                                                            | R2             | Aberta |

Se for saúde (psicologia, nutrição), anotações viram prontuário com exigências do CFP/CFM?                                   | Alto    | Começar por serviços gerais e psicologia; anotações do R3 como "notas privadas", sem promessa de prontuário.                                                | R3             | Aberta |
| Q-06 | Nome definitivo do produto e domínio (o projeto usa "Agenda" provisoriamente).                                                                       | Médio   | Definir antes da página pública (R2), que expõe o domínio.                                                                                                  | R2             | Aberta |
| Q-07 | No celular, a visão "semana" mostra 3 dias com rolagem ou vira a visão de dia?                                                                       | Médio   | 3 dias com rolagem lateral; validar em protótipo com 5 usuários.                                                                                            | US-010         | Aberta |

| Q-09 | O en-US é necessário no MVP ou só a infraestrutura (já pronta no template)?                                                                          | Baixo   | Manter a infraestrutura e traduzir as telas do MVP; o custo é baixo e o teste de paridade já existe.                                                        | —              | Aberta |
