## Como usar esta pasta

1. Leia `requirements/VISION.md` para entender o produto.
1. Leia `ARCHITECTURE-GUIDE.md` para entender camadas, fluxos e convenções.
1. Navegue para os READMEs locais nas pastas de `src/` para detalhes de implementação.
1. Siga o `ONBOARDING.md` para criar novas features.
1. Consulte `COMMIT-CONVENTIONS.md` antes de commitar.
1. Use `CODE-REVIEW-CHECKLIST.md` ao revisar PRs.
1. Consulte `decisions/` para entender o porquê das decisões arquiteturais (ADR).
