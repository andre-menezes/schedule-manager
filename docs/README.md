## Como usar esta pasta

1. Leia `ARCHITECTURE-GUIDE.md` para entender camadas, fluxos e convenções.
2. Navegue para os READMEs locais nas pastas de `src/` para detalhes de implementação.
3. Siga o `ONBOARDING.md` para criar novas features.
4. Consulte `COMMIT-CONVENTIONS.md` antes de commitar.
5. Use `CODE-REVIEW-CHECKLIST.md` ao revisar PRs.
6. Consulte `decisions/` para entender o porquê das decisões arquiteturais (ADR).
